Galaxia Installer

Install firmware made with the unofficial Galaxia SDK on an M-VAVE Galaxia, over USB from Chrome or Edge, and go back to M-VAVE's own firmware whenever you like. Not made or supported by M-VAVE.

1. The pedal

Plug it in with a USB data cable and close other apps that use MIDI. Chrome will ask to let this page use MIDI devices.

Pedal not found?

The page only talks to ports named after the pedal ("Galaxia", or "FM-1" while it runs M-VAVE's firmware). If your firmware's USB name is something else, enter part of it.

2. The firmware

3. Install

Keep the pedal powered and this page open until it finishes, about half a minute. Turn the volume down, as a new firmware can make unexpected sounds.

Experimental, with no warranty of any kind. An Elemental Pro is the same board as the Galaxia and takes the same firmware. The page talks to no other M-VAVE device.

    
A firmware that doesn't start can always be put right through the chip's own bootloader with the SDK's gx_flash.py, which can also back up your pedal first. A backup keeps what this page can't: your pedal's own copy of its firmware and settings.
