Galaxia Installer

Install firmware built with the unofficial Galaxia SDK on an M-VAVE Galaxia pedal, over USB, from Chrome or Edge. Not made or supported by M-VAVE.

1. The pedal

Plug it in with a USB data cable and close other apps that use MIDI. Chrome will ask to let this page use MIDI devices.

Pedal not found?

The page only talks to ports named after the pedal. If your firmware's USB name doesn't include "Galaxia", enter part of its name.

2. The firmware

Choose a .fwsc package made with tools/gx_pkg.py. It stays in this browser and isn't uploaded.

3. Install

Keep the pedal powered and this page open until it finishes, about half a minute. Turn the volume down, as a new firmware can make unexpected sounds.

Log 

    

  


  

    
Experimental, with no warranty of any kind. A pedal still on M-VAVE's firmware needs its first SDK firmware installed with gx_flash.py, and that tool is also how you recover one that no longer starts.

    
Going back to M-VAVE's firmware: this page can't do it. Restore the backup you made before your first install with gx_flash.py restore. Keep that file safe, as this project can't supply a replacement.
